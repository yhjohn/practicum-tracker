# Goal

Create a `Log Book` table in admin panel with filament with a time logger functionality.

The most important and ultimate goal for you is that you can export XLSX in the format of the XLSX in the reference doc in the same folder.
Of course the xlsx is currently having some demo text but you'll figure this out.

# Description

You're a counselling student practicing in the practicum. You need a page to keep track and eventually export this data to XLSX. for now though you need to collect data. You can refer to the xlsx in the same folder.

You need a clear view of "Time Log" that is able for you to track what you did throughout the weeks. Now, 2 of the most important modules that you use is Individual Counselling Log and Group Counselling Log. Both of this will eventually be the model. The Group Counselling Log will come as a future model, but for now, it is imperative that you keep that in mind, since it will most likely be something similar to the Individual Counselling Log model

In the individual counselling log, you already log your week / time and client so that is all good. you will need to use this information as part of data collation / display / export.

You can totally Ignore the "couple counselling" as that is something that you are not going to use in this practicum, however you will still need this "type" as it is part of the report.

** Category and Component **

You can refer to the XLSX but as a breakdown

* Direct Client Contact
    * Individual Counselling
    * Group Counselling
    * Career/Family/Couple Counselling
* Other Activity
    * Professional Development
    * Guidance and Admin
    * Supervision
    * Face-to-face seminars


# Scope

At the end of the day you'll want

1. A page in filament admin call `Log Book` that you can view a table of information, you can also filter this by week, lets say week 1, you want to see what you did for week 1.

2. A modal/function that you can quickly input week, date, time spent and description for non direct client contact component such as guidance and admin

3. A export buttont to export this into a XLSX format.
